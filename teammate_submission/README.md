# Teammate source snapshot

This folder preserves the submitted files as received for review. Do not start the server from these duplicate filenames. The integrated entry points are the repository-root `app.py` and `viz.py`, with the browser client in `evaluator_ui/index.html`; tests for those canonical files are in `tests/`.

The submitted `app (2).py` map endpoint reads and displays reference routes. That behavior is deliberately not carried into the integrated evaluation UI.
